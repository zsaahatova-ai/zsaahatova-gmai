# Serverless функция: бағдарламалық кодты іске қосу

## Мақсаты
Serverless қызметінде (Vercel Functions, AWS Lambda аналогы) Python кодын іске қосу.

## Орындалған қадамдар
1. GitHub репозиторийі құрылды
2. `api/hello.py` функциясы жазылды
3. Репозиторий Vercel-ге импортталды және Deploy жасалды
4. Функция `/api/hello` сілтемесі арқылы тексерілді
5. Vercel Logs бөлімінде журнал қаралды

## Нәтиже
Функция JSON қайтарады: sum = 100, average = 25.0

## Қорытынды
Serverless функция серверді басқармай-ақ кодты сұраныс бойынша іске қосуға мүмкіндік береді.
